# Екран завантаження та логотип-іконка

- **Логотип.** Еталонний SVG лежить в одному місці: `window.DL_LOGO_SVG` у `<head>`. Екземпляри створює `dlLogoHTML({cls,label,draw})` (у JS-коді — `dlLogo()`); кожен отримує свій id градієнта. Іконка використовується:
  - на екрані завантаження;
  - у шапці (`#hdrLogo`), бічному меню (`.side-head`) і героях (`.hero-brand`);
  - як `<link rel=icon>` (SVG data URI) і `apple-touch-icon` (PNG 180×180, зрендерений із того ж SVG).
  - Додатково: `theme-color #044F5E`.
- **Екран `#dlSplash`.** Розмітка, CSS та API `window.DLS` інлайн у HTML, ще до основного скрипту. Google Fonts підвантажуються без блокування першого кадру. Unbounded береться лише тоді, коли шрифт уже в кеші, інакше — Verdana, тож напис не «стрибає».
- **Етапи** (усі реальні, з `boot()`):

  | Подія | Статус | Прогрес |
  |---|---|---|
  | старт | «Підключаємось…» | .12 |
  | db/user отримано | «Завантажуємо колектив…» | .35 |
  | перший знімок staff | «Оновлюємо графік і задачі…» + привітання | .65 |
  | staff + tasks + тиждень | «Майже готово…» → `DLS.done()` | .92 |

  Якщо staff прийшов, а решта затримується, екран однаково ховається через 4 с.
- **Інші стани:**
  - `DLS.fail()` — немає бази, помилка знімка до завантаження staff або виняток у `boot()`;
  - через 8 с — «триває довше» з кнопкою «Оновити»;
  - мінімальний показ 700 мс (300 мс для reduced motion);
  - вихід: opacity + scale 1.02 за 300 мс.
- **Перегляд,** коли завантаження дуже швидке: додайте до адреси `#splash` — екран тримається 6 с.
