# Облік роботи за день (Facility)

Заміна таблиці «База обліку роботи УК». Facility → плитка «Облік роботи».

- **Хто веде:** уся команда Facility (ролі manager, senior, engineer, director, ceo, dev, test). Плашки працівників угорі; кожен обирає себе. Усі бачать записи всіх; редагує автор, власник запису або адміністратор.
- **Запис** (`wlog`): `sid`, `with[]` (разом із, запис видно й у їхньому обліку), `date`, `src` (джерело), `cat` (категорія), `loc` (де), `by` (хто призначив, типово «За регламентом»), `sla` A/B/C, `st` done/prog/moved, `text`, `at`, `author`.
- **Швидке заповнення:** «Типові роботи» — найчастіші записи людини за 90 днів (+ шаблони з таблиці УК, поки історії мало); «Повторити <дата>» — копіює вибрані записи з останнього заповненого дня.
- **Нагадування о 16:00:** у застосунку — пункт «Заповніть облік роботи за сьогодні» у Facility і на вкладці. Листом — перший застосунок команди, відкритий після 16:00, шле Gmail тим, хто ще не заповнив і за графіком працює; позначка дня в `wl_rem/<дата>`. Без відкритого застосунку лист не піде (сервера немає).
- **Word-звіт:** «Звіт Word» → місяць + усі або одна людина. Альбомна сторінка: титул, зведення, категорії, далі кожен працівник з нової сторінки, усі дні від 1-го до останнього числа (вихідні виділені, порожні дні позначені).
