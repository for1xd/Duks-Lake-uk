# Graphite Glass (тестова тема для Dev)

Вмикається в меню (☰) → «Тест» → «Graphite Glass (тест)». Лише для Dev і лише в цьому браузері (`localStorage` `dl.gg`), команда нічого не бачить.

- Код: CSS-блок «Graphite Glass (тест для Dev)» у кінці останнього `<style>` і функції `ggOn / applyGG / toggleGG / ggBtn` поруч з `applyV2`.
- Токени перевизначають наявні змінні (`--bg`, `--surface`, `--fg`, `--accent`…) + свої `--gg-*` (градієнт фону й поверхонь, обідки, тіні, скло, моно-шрифт). Логіка застосунку не змінюється.
- Світла й темна теми — від наявного перемикача теми (`data-theme`) або системи.
- Шрифти Inter і JetBrains Mono вантажаться тільки коли тема увімкнена.
- Увімкнення вимикає старий тест `v2`, щоб стилі не змішувались.

Не зроблено (свідомо, на цьому етапі): агенти, хуки й команди з промту (у проєкті немає збірки, lint, typecheck чи Playwright — це один HTML-файл), окрема сторінка-вітрина, посторінкова доводка модулів.
