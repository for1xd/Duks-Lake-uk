# Graphite Glass (тестова тема для Dev)

Вмикається в меню (☰) → «Тест» → «Graphite Glass (тест)». Лише для Dev і лише в цьому браузері (`localStorage` `dl.gg`), команда нічого не бачить.

- Код: CSS-блок «Graphite Glass (тест для Dev)» у кінці останнього `<style>` і функції `ggOn / applyGG / toggleGG / ggBtn` поруч з `applyV2`.
- Токени перевизначають наявні змінні (`--bg`, `--surface`, `--fg`, `--accent`…) + свої `--gg-*` (градієнт фону й поверхонь, обідки, тіні, скло, моно-шрифт). Логіка застосунку не змінюється.
- Світла й темна теми — від наявного перемикача теми (`data-theme`) або системи.
- Шрифти лишаються як у застосунку (Inter і моно-шрифт прибрано за відгуком власника). Привітання — темна графітова панель.
- Увімкнення вимикає старий тест `v2`, щоб стилі не змішувались.

Не зроблено (свідомо, на цьому етапі): агенти, хуки й команди з промту (у проєкті немає збірки, lint, typecheck чи Playwright — це один HTML-файл), окрема сторінка-вітрина, посторінкова доводка модулів.

## Етап 2 (16.11.2026): дзеркальні теми, кнопки шапки, меню
- Усі кольори, тіні, обідки — токени `--gg-*`; темна тема відрізняється лише значеннями (блок продубльовано для `prefers-color-scheme` і `data-theme`, правити обидва).
- Привітання: `--gg-hero*` (срібло у світлій, графіт у темній, той самий блік і тінь). Пігулки, бейджі ролей, чипи — тонована напівпрозора поверхня `--gg-tint`, без інверсії.
- Скляна плашка: `--gg-surf` (напівпрозорий градієнт) + `--gg-in` (верхній блік, нижня тінь) + обідок `--gg-rimd` + `--gg-out` + відблиск `::before` (`--gg-hi`). Без `backdrop-filter` на картках (продуктивність).
- Кнопки шапки: 48 px / 40 px на телефоні, обідок 0.5 px всередині + 1 px зовні, блік `--gg-btn-hi`, стани hover/active/disabled/focus (`--gg-focus`). Кнопки з фірмовим кольором (`.tg`, `.mt-pdf`, `.mt-own`) і KPI-плашки `.dz-k.hero` не чіпаються.
- Меню: шторка справа на всю висоту (`--gg-sheet`, ≥ 98 %), затемнення `--gg-dim`, скрол сторінки заблоковано класом `body.menu-open` (ставиться в `openMenu`, знімається в `closeMenu`).
- Перевірка: агенти в `.claude/agents/` (design-critic, a11y-auditor, design-system-guardian, bug-hunter); скріншоти — тестові сторінки з CSS застосунку у вбудованому браузері.
