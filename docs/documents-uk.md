# Документи УК — каталог посилань на Google Диск

Файли зберігаються **тільки на Google Диску**. Застосунок зберігає лише назви та посилання, а доступ до самих файлів налаштовується на Диску.

## Дані — колекція `docs`

| Документ | Що зберігає |
|---|---|
| `_cfg` | `{rootUrl, v}` — посилання на кореневу папку «УК Документи» |
| `f_<id>` | `{kind:'folder', name, icon, color, url, order, v}` — папка |
| `d_<id>` | `{kind:'doc', folderId, name, url, type, note, order, by, bySid, at, v}` — документ |

- **Перше наповнення** (`dkSeed`) спрацьовує, коли колекція порожня. Воно створює 8 папок із порожніми посиланнями та `_cfg`. Від дублів захищає lease на `docs/_cfg`. Посилань у коді немає.
- **Запис** (`dkPut`) іде з перевіркою версії `v`. Якщо запис уже змінив хтось інший, зміна не зберігається і показується повідомлення.
- **Журнал.** Кожна зміна пишеться в `log` з префіксом «Документи УК:».

## Права

- Додають і редагують ролі `manager`, `director` (Керуючий УК) і `dev`.
- `staff.perms.docsEdit` перекриває роль: `true` — дозволити, `false` — заборонити.
- Решта UK — тільки читання.

## Тип документа (`dkType`)

| Що в посиланні або назві | Тип |
|---|---|
| `/document/` | Docs |
| `/spreadsheets/` | Sheets |
| `/presentation/` | Slides |
| `/folders/` | папка |
| `.pdf` | PDF |
| `.jpg`, `.png` та інші зображення | зображення |
| `.xlsx` | Excel |
| `.docx` | Word |
| усе інше | файл |
