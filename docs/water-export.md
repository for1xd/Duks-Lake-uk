# Облік води: Excel-звіти

Код: блок `WXL:BEGIN … WXL:END` в `index.html` (бібліотека [ExcelJS](https://github.com/exceljs/exceljs) 4.4.0, вантажиться з CDN при першому експорті). У застосунку: Facility → Облік → Вода → «Вивантажити в Excel».

## Вхідні дані
`WXL.build(ExcelJS, data, mode)` — чиста функція: отримує об'єкт `data` і повертає книгу ExcelJS. `mode`: `"acc"` — «Для бухгалтерії», `"full"` — «Повний облік». У застосунку `data` збирає `wExportData(period)`.

```jsonc
{
  "period": { "key": "2026-10", "label": "Жовтень 2026" },   // label іде в заголовки аркушів
  "generatedAt": "01.11.2026 12:00",                         // підпис «Сформовано …»
  "bill": { "m3": 1850.0, "uah": 98420.50 },                 // рахунок Водоканалу; null — не внесено
  "tolerancePct": 5,                                         // допустима похибка відхилення, % (на дашборді її можна змінити)
  "buildings": [                                             // об'єкти обліку води, у порядку виведення
    {
      "id": "b12",
      "name": "Будинок 1.2",
      "meters": [                                            // 1 резидент/приміщення → 1..N лічильників
        {
          "id": "m026",
          "type": "common",                                  // "common" — загальнобудинковий, "resident" — комерційне приміщення
          "active": true,                                    // false — не діючий (не входить у суму загальнобудинкових)
          "section": null,                                   // частина об'єкта: "Будинок 2" / "Будинок 4" → окремий аркуш
          "floor": "",
          "room": "",
          "tenant": "Діючий загальнобудинковий",
          "serial": "BSEN0124775845",                        // глобально унікальний; "" — лічильника немає
          "start": 5388.0,                                   // показник на початок, м³ (null — не внесено)
          "end": 6534.0                                      // показник на кінець, м³
        },
        { "id": "m031", "type": "resident", "active": true, "section": null, "floor": "1", "room": "104",
          "tenant": "Федоренко", "serial": "42120539", "start": 0.0, "end": 3.0 }
      ]
    }
  ],
  "checks": {                                                // необов'язково: якщо немає, рахується через WXL.checks(data)
    "dupSerials": [],                                        // номери, що повторюються
    "missing": [],                                           // лічильники без показників
    "negative": []                                           // кінцевий показник менший за початковий
  }
}
```

Правила:
- Якщо в резидента 2 лічильники, це два елементи `meters` з однаковими `tenant` і `room`. У звіті вони йдуть окремими рядками.
- `serial: ""` і немає показників: у колонці «Номер лічильника» курсивом пишеться «немає лічильника».
- Об'єкт із `section` (наприклад, «Будинки 2 і 4») дає окремий аркуш на кожну частину. Спільні загальнобудинкові лічильники (без `section`) у «Повному обліку» виносяться на окремий аркуш, і на дашборді вони порівнюються із сумою резидентів усіх частин.

## «Для бухгалтерії» (`acc`)
- Аркуш на кожен будинок, тільки лічильники резидентів.
- Рядок 1 — об'єднаний заголовок `Облік води | <будинок> | <місяць рік>`. Рядок 3 — шапка колонок (фон `#1a365d`, білий жирний текст), закріплена разом із заголовком.
- Колонки: Поверх · Номер приміщення · Резидент · Номер лічильника · Показник на початок (м³) · Показник на кінець (м³) · Спожито (м³).
- «Спожито» — формула `=IF(AND(ISNUMBER(E5),ISNUMBER(F5)),F5-E5,"")`: бухгалтер змінює показник, і сума перераховується. Внизу «Разом по резидентах» — формула `SUM`.
- Тонкі межі, формат `#,##0.00`, друк на A4: у ширину однієї сторінки, шапка повторюється, нумерація сторінок.

## «Повний облік» (`full`)
- **Дашборд** (перший аркуш):
  1. Рахунок Водоканалу (м³, грн — жовті клітинки можна редагувати) vs фактичне споживання комплексу (сума загальнобудинкових); різниця в м³ і в грн за ціною 1 м³ з рахунку.
  2. Зведення по будинках: загальнобудинковий (м³), сума по резидентах (м³), відхилення (м³ і %). Усі значення — формули-посилання на аркуші будинків, назви — гіперпосилання на ці аркуші.
     - Умовне форматування відхилення: > 0 — зелений текст; < 0 — червоний текст; |відхилення| більше допустимої похибки (% від загальнобудинкового, клітинка поруч із таблицею) — червоний фон.
  3. Перевірка даних: лічильники без показників, повтори номерів, від'ємне споживання.
- **Аркуші будинків:** як у бухгалтерії, плюс блок «Загальнобудинкові лічильники» і підсумки «Загальнобудинкові (діючі)» та «Відхилення» з тим самим умовним форматуванням.
