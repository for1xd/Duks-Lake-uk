# src/ — код застосунку, розбитий на модулі (лише для читання)

Застосунок Duck's Lake — це один файл `index.html`: так його публікує Claude. Індексатори коду (Graphify тощо) не розбирають код усередині `<script>` в HTML, тому їхня схема зводилась до кількох файлів.

Ця папка — **згенерована копія** того самого коду, розрізана на модулі за розділами застосунку: карта, обхід будівель, клінінг, документи УК, облік, чат, покер… Вона потрібна, щоб схема коду розгалужувалась до функцій і зв'язків.

- **Не редагуйте ці файли вручну.** Усі правки робляться в `index.html`.
- **Оновлення:** `python3 tools/split_src.py`. Після кожного push зі зміненим `index.html` GitHub Actions (`.github/workflows/split-src.yml`) оновлює папку сам.
- **`main.js`** — порядок модулів, як в `index.html`. Усі модулі ділять одну глобальну область видимості.
- **Перевірка:** кожен модуль окремо — коректний JS, а кількість іменованих функцій збігається з оригіналом.
